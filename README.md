# Доска объявлений

*серверная часть была дана в задании, мной реализована клиентская часть, дизайн

Одностраничное приложение для публикации и просмотра объявлений трёх категорий: **недвижимость**, **авто** и **услуги**. Можно создавать объявления, редактировать их, искать по названию и фильтровать по категории.

## Возможности

- Список объявлений с пагинацией (по 5 на странице, размер страницы можно менять)
- Поиск по названию и фильтр по категории (авто / недвижимость / услуги / все)
- Страница объявления с характеристиками, ценой и описанием
- Форма создания и редактирования: набор полей зависит от выбранной категории
- Валидация обязательных полей

## Стек

- **React** + **TypeScript**
- **React Router** для навигации
- **MobX** (`mobx-react-lite`) для состояния
- **Ant Design** 

## Запуск

```bash
npm install
npm run dev
```

Приложение ходит на бэкенд по относительным путям (`/items`, `/items/:id`), поэтому API должен быть доступен с того же origin или проксироваться через dev-сервер.

Настройки серверной части находятся в файле /server/README-API.md

## API

Фронтенд ожидает такие эндпоинты:

| Метод | Путь         | Что делает                       |
| ----- | ------------ | -------------------------------- |
| GET   | `/items`     | список всех объявлений           |
| GET   | `/items/:id` | одно объявление                  |
| POST  | `/items`     | создать объявление               |
| PUT   | `/items/:id` | обновить объявление              |


## Маршруты

| Путь        | Страница                                      |
| ----------- | --------------------------------------------- |
| `/`         | редирект на `/list`                           |
| `/list`     | список объявлений                             |
| `/item/:id` | карточка объявления                           |
| `/form`     | создание объявления                           |
| `/form?id=` | редактирование (категорию менять нельзя)      |

## Модель данных

Все объявления имеют общие поля: `name`, `description`, `location`, необязательный `image`. Остальное зависит от категории (`type`):

| Категория     | Дополнительные поля                                          |
| ------------- | ------------------------------------------------------------ |
| Недвижимость  | `propertyType`, `area`, `rooms`, `price`                     |
| Авто          | `brand`, `model`, `year`, `mileage`                          |
| Услуги        | `serviceType`, `experience`, `cost`, `workSchedule` (необяз.) |

Типы описаны в `src/types.ts` как дискриминируемое объединение `RawItem`, поэтому TypeScript сам сужает тип по полю `type`.

Для списка сырые данные превращаются в `Listing` : считается цена, собираются строки характеристик, подставляется картинка-заглушка.

## Как устроено состояние

Всё лежит в одном сторе `ItemsStore`:

- `items`, `loading`, `error`: список объявлений
- `currentItem`, `itemLoading`, `itemError`: открытое объявление
- `searchQuery`, `category` и вычисляемое `filteredItems`: поиск и фильтрация на клиенте
- `fetchItems`, `fetchItem`, `postItem`, `updateItem`: работа с сервером

Страницы обёрнуты в `observer` и перерисовываются при изменении стора.
